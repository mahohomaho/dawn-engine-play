# ギルド再建記

スマートフォン向けの周回型ブラウザゲーム。父が残したギルドの借金を返し、魔王軍の襲来を乗り越えて最終決戦へ進みます。

## 遊び方

1. 職業と最初の相棒を選ぶ。
2. 採取や冒険でGを得る。遠征中の品とGは帰還時に確定する。
3. 期限までに受付で返済、または襲来を撃退する。日付は就寝でのみ進む。
4. 失敗すると天界で記憶を得る。恒久強化を購入して新たな周回を始める。
5. 六つの期限イベントを突破すると最終決戦が開く。

通常スキルは12系統・各80個で、全域を初日から閲覧できます。職業専用は3系統・各40個、天界は80個です。ボスの秘伝書を使うと新しい隠しノードが現れます。星図はドラッグ、ピンチ、ホイール、検索で操作できます。

セーブはブラウザの `localStorage` に自動保存されます。「その他」からJSONの書き出し・読み込みができます。別ブラウザへ移す際に使ってください。

## 開発

静的ファイルのみで動き、ビルドは不要です。`index.html` をローカルHTTPサーバーで開けます。

```sh
node test.js
```

`data.js` に数値とツリー定義、`engine.js` に状態遷移、`ui.js` に画面と操作を分離しています。ゲームの出典仕様は非公開の `dawn-engine/GAME_DESIGN_COMPLETE_V2.md` です。
