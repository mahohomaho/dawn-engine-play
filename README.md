# ギルド再建記

スマートフォン横画面向けの周回型ブラウザゲーム。父が残したギルドの借金を返し、魔王軍の襲来を乗り越えます。20回目の襲来を率いる魔王を倒すと物語が完結します。[公開ページ](https://mahohomaho.github.io/dawn-engine-play/) から遊べます。

## 遊び方

1. 職業と最初の相棒を選ぶ。
2. 採取や冒険でGを得る。遠征中の品とGは帰還時に確定する。
3. 期限までに受付で返済、または襲来を撃退する。日付は就寝でのみ進む。
4. 失敗すると天界で記憶を得る。恒久強化を購入して新たな周回を始める。
5. 返済と襲来を各20回突破する。20回目の襲来が魔王との決戦。各期限は前の目標を達成した日の4日後です。

天界では記憶を使い、攻勢・守護・生計の永続鍛錬を何段階でも購入できます。初周は15日目前後の敗北を想定した難度です。

襲来を3回撃退するごとに作戦会議が開きます。進軍・返済・研究のどれを強化するか選び、その周のビルドを変えられます。詳しいルールは[試遊後の作戦会議仕様](https://github.com/mahohomaho/dawn-engine/blob/main/GAME_DESIGN_PLAYTEST_V6.md)に記載しています。

宝物庫では素材・換金品・売却専用の護符を「全部売る」「半分売る」でまとめて売却できます。半分は品目ごとに端数を残します。装備・本・回復薬・振り直し札は対象外です。

通常スキルは12系統で、購入済みと次の候補だけを星図に表示します。職業専用の技と、秘伝書で現れる隠しノードもあります。カタログには40品のアイテム、74ノード、20種類のペット第2スキル、30品の料理を収録しています。星図はドラッグ、ピンチ、ホイール、検索で操作できます。

セーブはブラウザの `localStorage` に自動保存されます。「その他」からJSONの書き出し・読み込みができます。別ブラウザへ移す際に使ってください。

## 開発

静的ファイルのみで動き、ビルドは不要です。`index.html` をローカルHTTPサーバーで開けます。

```sh
node build-catalog.js
node test-v3.js
node playthrough.js
```

`data.js` と `v3-data.js` に数値とツリー定義、`engine.js` と `v3-engine.js` に状態遷移、`ui.js` に画面と操作を分離しています。カタログは非公開の `dawn-engine/GAME_SPEC_LANDSCAPE.md` から生成しました。試遊用の数値は仕様書の確定値ではありません。収録した全効果が実際の計算へ接続済みではないため、プレイしながら順次調整します。
