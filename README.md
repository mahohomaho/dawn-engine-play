# ギルド再建記

スマートフォンで遊べる周回型ブラウザゲーム。父が残したギルドの借金を返し、魔王軍の襲来を乗り越えます。20回目の襲来を率いる魔王を倒すと物語が完結します。[公開ページ](https://mahohomaho.github.io/dawn-engine-play/) から遊べます。

## 遊び方

最初の周回では、冒険から採取・帰還・売却・返済まで短い案内が順に表示されます。「案内を閉じる」で中断でき、「その他 → 遊び方」から再表示できます。

1. 職業と最初の相棒を選ぶ。
2. 採取や冒険でGを得る。遠征中の品とGは帰還時に確定する。
   冒険タブの地図で採取地（✿）か探索地（⚔）を選び、詳細を見て出発します。エリア内は「次へ」で進みます。
3. 期限までに受付で返済する。魔王軍の襲来前には3日前から予告が届くので、仲間・装備・スキルを整える。到着日の朝、ギルド前の広場で防衛戦が自動で始まる。早めに広場で迎撃することもできる。日付は就寝でのみ進む。
4. 失敗すると天界で記憶を得る。恒久強化を購入して新たな周回を始める。
5. 返済と襲来を各20回突破する。20回目の襲来が魔王との決戦。各期限は前の目標を達成した日の4日後です。

天界では記憶を使い、攻勢・守護・生計の永続鍛錬を何段階でも購入できます。初周は15日目前後の敗北を想定した難度です。

襲来を3回撃退するごとに作戦会議が開きます。進軍・返済・研究のどれを強化するか選び、その周のビルドを変えられます。

宝物庫では同種の素材・換金品を「薬草 ×5」のようにまとめて表示します。品目をタップすると由来や手触りが分かる説明、実際の用途、売値を確認し、1個または同種をまとめて売却できます。草原で採れる薬草も職人のポーション調合に使えます。全品目の「全部売る」「半分売る」は折りたたみ欄から利用できます。半分は品目ごとに端数を残します。装備・本・回復薬・振り直し札は一括売却の対象外です。

通常スキル12系統と職業専用の技5系統を、ひとつのスキル星図に配置しています。未取得の遠い星は暗いアイコンと線だけを表示し、手前を取得するまで名前や効果を伏せます。強力なスキルは大きな星として描き、秘伝書由来の枝は読むまで見せません。カタログには40品のアイテム、74ノード、20種類のペット第2スキル、30品の料理を収録しています。星図はドラッグ、ピンチ、ホイール、発見したスキルの検索、系統へのジャンプ、全体表示で操作できます。購入条件と効果は従来のままです。天界の恒久スキルは周回後に開く独立した星図です。

セーブはブラウザの `localStorage` に自動保存されます。「その他」からJSONの書き出し・読み込みができます。別ブラウザへ移す際に使ってください。

## ワールドマップ

地図には採取地3か所、探索地3か所、ギルドを配置しています。最初は花の草原と若葉の森だけが見えます。採取5回または森の中継点10歩で霧の森、森の中継点20歩で廃鉱が見つかります。霧の森への到達または廃鉱の中継点10歩で雷鳴の洞窟、廃鉱の中継点20歩で星見の塔が見つかります。地図に見えても、霧の森と廃鉱は若葉の森のボス、雷鳴の洞窟と星見の塔は廃鉱のボスを討伐するまで出発できません。発見・到達・ボス討伐は周回開始時にリセットされます。

未発見地は青白い霧に隠れ、発見時には霧が晴れます。発見と出発解放は別判定です。移動スタミナ、戦闘、採取、報酬の計算は従来の定義を使用します。売却・依頼達成・勝利のG報酬は画面上部に短く表示します。

## ギルド防衛戦

魔王軍は返済達成日の4日後の朝に到着します。到着前の3日間は警告が届き、次の敵部隊と必要な準備を確認できます。防衛戦では編成中の主人公、仲間最大3人、ペット1匹が、ギルド前のドット絵の広場で戦います。操作は通常戦闘と同じラウンド制で、自動戦闘と倍速も使えます。勝利後は次の返済へ進み、敗北した場合は天界へ移ります。背景は `guild-square-defense-v1.png` を使用し、キャラクターは透過ドット絵のまま表示します。

## キャラクター画像

`character-art.js` に主人公6職と仲間18人の画像パス・表示名・特化をまとめています。画像は `assets/characters/` の透過PNGで、既存の騎士画像だけは `hero-knight-v1.png` を参照します。職業変更に合わせてギルドと冒険中の主人公画像が切り替わり、既存の仲間IDと一致する画像は冒険中に表示されます。「その他」のキャラクター図鑑で24体すべてを確認できます。現在のゲームシステムに未実装の職業・仲間は図鑑での鑑賞用です。`provisional` が真の仲間名・設定は仮案です。

敵・相棒・アイテムは `sprite-art.js` でIDと透過PNGを対応させています。画像は `assets/sprites/` に置き、敵と相棒は64×64、アイテムは32×32の論理ドットを最近傍補間で拡大したものです。相棒は選択画面・編成・冒険隊列、敵は遭遇と戦闘、アイテムは宝物庫・戦利品・図鑑に表示されます。同系統の装備や本は一部の意匠を共有します。

`action-feedback.js` は行動前後の所持品と戦闘ログの差から演出内容を作ります。採取・宝箱の獲得品、与ダメージ・被ダメージ・会心、勝利時の獲得Gを探索背景へ短く表示します。演出はゲームの戦闘・報酬計算へ影響しません。

## 装備と仲間の確認

宝物庫には主人公の装備枠を表示します。武器・防具・装飾品は各1枠で、候補の「比較・装備」から現在の品との差と装備先を確認できます。仲間の個別装備枠は現行の戦闘ルールにはありません。

ギルドの「仲間」や宝物庫から画像付きの仲間一覧、キャラクター詳細、ステータス内訳を開けます。人間キャラクターには現状レベル制がなく、回避判定もありません。専用画像が未登録の仲間には、同じ職業のドット絵を仮絵として表示します。
