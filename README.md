# ギルド再建記

スマートフォン横画面向けの周回型ブラウザゲーム。父が残したギルドの借金を返し、魔王軍の襲来を乗り越えます。20回目の襲来を率いる魔王を倒すと物語が完結します。[公開ページ](https://mahohomaho.github.io/dawn-engine-play/) から遊べます。

## 遊び方

最初の周回では、冒険から採取・帰還・売却・返済まで短い案内が順に表示されます。「案内を閉じる」で中断でき、「その他 → 遊び方」から再表示できます。

1. 職業と最初の相棒を選ぶ。
2. 採取や冒険でGを得る。遠征中の品とGは帰還時に確定する。
   冒険タブの地図で採取地（✿）か探索地（⚔）を選び、詳細を見て出発します。エリア内は「次へ」で進みます。
3. 期限までに受付で返済、または襲来を撃退する。日付は就寝でのみ進む。
4. 失敗すると天界で記憶を得る。恒久強化を購入して新たな周回を始める。
5. 返済と襲来を各20回突破する。20回目の襲来が魔王との決戦。各期限は前の目標を達成した日の4日後です。

天界では記憶を使い、攻勢・守護・生計の永続鍛錬を何段階でも購入できます。初周は15日目前後の敗北を想定した難度です。

襲来を3回撃退するごとに作戦会議が開きます。進軍・返済・研究のどれを強化するか選び、その周のビルドを変えられます。詳しいルールは[試遊後の作戦会議仕様](https://github.com/mahohomaho/dawn-engine/blob/main/GAME_DESIGN_PLAYTEST_V6.md)に記載しています。

宝物庫では同種の素材・換金品を「薬草 ×5」のようにまとめて表示します。品目をタップすると由来や手触りが分かる説明、実際の用途、売値を確認し、1個または同種をまとめて売却できます。草原で採れる薬草も職人のポーション調合に使えます。全品目の「全部売る」「半分売る」は折りたたみ欄から利用できます。半分は品目ごとに端数を残します。装備・本・回復薬・振り直し札は一括売却の対象外です。

通常スキル12系統と職業専用の技5系統を、ひとつのスキル星図に配置しています。未取得の遠い星は暗いアイコンと線だけを表示し、手前を取得するまで名前や効果を伏せます。強力なスキルは大きな星として描き、秘伝書由来の枝は読むまで見せません。カタログには40品のアイテム、74ノード、20種類のペット第2スキル、30品の料理を収録しています。星図はドラッグ、ピンチ、ホイール、発見したスキルの検索、系統へのジャンプ、全体表示で操作できます。購入条件と効果は従来のままです。天界の恒久スキルは周回後に開く独立した星図です。

セーブはブラウザの `localStorage` に自動保存されます。「その他」からJSONの書き出し・読み込みができます。別ブラウザへ移す際に使ってください。

## ワールドマップ

地図には既存の採取地3か所、探索地3か所、ギルドを配置しています。最初は花の草原と若葉の森だけが見えます。採取を5回行うか森の中継点10歩に達すると霧の森、森の中継点20歩で廃鉱、霧の森への到達で古代の湿地、廃鉱の中継点20歩で星見の塔が見つかります。既存の関連スキルを取得した場合も対応する地域が見つかります。発見しても出発には従来のスキル条件が必要です。発見・到達状態は周回開始時にリセットされます。

地図の発見は演出と行き先の表示だけに使い、移動スタミナ、戦闘、採取、報酬の計算は従来の定義を使用します。

## キャラクター画像

`character-art.js` に主人公6職と仲間18人の画像パス・表示名・特化をまとめています。画像は `assets/characters/` の透過PNGで、既存の騎士画像だけは `hero-knight-v1.png` を参照します。職業変更に合わせてギルドと冒険中の主人公画像が切り替わり、既存の仲間IDと一致する画像は冒険中に表示されます。「その他」のキャラクター図鑑で24体すべてを確認できます。現在のゲームシステムに未実装の職業・仲間は図鑑での鑑賞用です。`provisional` が真の仲間名・設定は仮案です。相棒画像は既存の仮画像を使います。

## 開発

静的ファイルのみで動き、ビルドは不要です。`index.html` をローカルHTTPサーバーで開けます。

```sh
node build-catalog.js
node test-v3.js
node playthrough.js
```

`data.js` と `v3-data.js` に数値とツリー定義、`engine.js` と `v3-engine.js` に状態遷移、`skill-map.js` に統合星図の配置、`skill-icons.js` に星の意匠、`item-lore.js` に品物の説明、`ui.js` に画面と操作を分離しています。カタログは非公開の `dawn-engine/GAME_SPEC_LANDSCAPE.md` から生成しました。試遊用の数値は仕様書の確定値ではありません。収録した全効果が実際の計算へ接続済みではないため、プレイしながら順次調整します。
